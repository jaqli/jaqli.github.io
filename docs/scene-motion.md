# 场景动作设计

所有位置都以原图的 1536 × 1024 坐标为准。动作遵循物体的固定点、受力方式和前后遮挡；用户切换减少动态效果或暂停时，整套场景共用的时钟停止。

原始 PNG 保持不变。浮动和风动物件从原图提取字符，原位置用邻近背景补齐；纸张和叶片保留各自固定点。固定背景先烘焙，再按小块更新全局字形；水面、云层、屏幕、纸张与灯光在 Worker 内更新局部 OffscreenCanvas，由浏览器合成，不传递全景位图。水面只在采样亮度时传递局部位图，消费后立即关闭；三个缓冲提前准备相邻时刻并随显示节奏混合。海鸥和十一组漂浮物的小纹理既换字也独立移动，隐藏入口与浮鸭同步。最多一个绘制请求在途，运动目标 60 Hz，云纹理和灯光按 30 Hz 更新，暂停及隐藏标签页停止调度。
