# 场景动作设计

所有位置都以原图的 1536 × 1024 坐标为准。动作遵循物体的固定点、受力方式和前后遮挡；用户切换减少动态效果或暂停时，整套场景共用的时钟停止。

| 元素 | 实现与边界 |
| --- | --- |
| 字号层次 | 基础间距约 4.6 px，每格均保留字符。0.5–1.3 倍九档字号，每 0.1 一档；稀疏的环境字符只在相邻档位之间变化。 |
| 三块电脑屏幕 | 保留更细的 ASCII 文本而不二次降采样。中间屏幕覆盖整个显示区：代码滚动、输入光标、CPU/MEM 侧栏、侧栏波形、帧数和底部状态分别更新。左屏有双通道波形与终端日志，右屏有曲线和频谱；12 fps 更新字符纹理，四边羽化接回原图反光，外壳不动。 |
| 左侧白色机器人眼睛 | 只提取两只眼睛的青色 LED。每 3.2 秒短暂眨眼，目光小幅偏移；头壳、天线、身体均固定。眼睛使用更细的字符，保留小尺寸表情。 |
| 机械云灯光 | 只替换中心发光区域。青色、紫色、暖橙、薄荷色平滑过渡，亮度按 4.4 秒周期呼吸，核心保留高光。云形外壳、线路不动。 |
| 红眼机器人 | 在原面板内眨眼、左右转动目光；红色 LED 保持自身颜色，机身不扭动。 |
| 两侧表情机器人 | 左下的双尖括号眼与右侧笑脸，在原面板内切换睁眼、开心眼、眨单眼、惊讶表情；不同相位，每种约 3.8 秒。 |
| 黄鸭与泳圈 | 作为同一个刚性物体，围绕水线中心上下浮动约 4 px，并轻微侧倾约 1.5°。眼睛、鸭嘴和泳圈相对位置不变；水线附近增加扩散涟漪。 |
| 钉在板上的纸 | 九张墙面便笺、板上纸张和显示器旁便条分别提取。固定上缘，偏移随离固定点的距离平方增加，下缘受到慢风与短促阵风影响；各自使用不同相位。 |
| 云层 | 沿窗外区域向一个方向漂移，速度约 6.8 原图 px/s，约为原来的 2.6 倍。移动的是云的颜色纹理，字符底层始终完整；窗口边缘渐变衔接。窗框、线缆、城市和太阳保持原位。 |
| 吊盆叶片 | 只提取绿色叶片，上部叶尖随风轻动，靠近茎部的位移逐渐趋零。花盆和吊绳固定。 |
| 海鸥 | 沿独立闭合航线飞行，穿插扇翼、滑翔和小幅转弯。移动后的羽翼遮挡天空字符，生活入口跟随鸟身。 |
| 水面 | 固定字符底层，叠加移动反光、局部椭圆涟漪以及浮鸭附近的波纹，避免挪走字符形成黑缝。 |
| 人物与室内结构 | 躯干、手臂、头部、桌椅、屏幕外框保持稳定。衣角末端仅有不足一个像素的起伏；不对人物施加大范围扭曲。 |

原始 PNG 保持不变。浮动和风动物件从原图提取字符，原位置用邻近背景补齐；纸张和叶片保留各自的固定点。背景云层与屏幕按较低频率更新缓存，物体位置和海鸥继续使用约 30 fps 的统一时钟。字符颜色图集在绘制前集中更新，以免逐字符写入和读取造成纹理反复上传。

回归检查覆盖场景入口、移动海鸥的点击区域、固定的躯干与手臂、水面覆盖率、独立屏幕更新、眼睛眨动、浮鸭刚性、纸张固定端、云与窗框的分离、混合字号、移动端、暂停与减少动态效果。
