# 场景动作设计

所有位置都以原图的 1536 × 1024 坐标为准。动作遵循物体的固定点、受力方式和前后遮挡；用户切换减少动态效果或暂停时，整套场景共用的时钟停止。

| 元素 | 实现与边界 |
| --- | --- |
| 字号层次 | 全景采用一套较疏网格，按约 5.6 px 横向间距安排，限制在 180–300 列，行距约为列距的 1.42 倍；字体基准按画面宽度独立确定。仍为 0.60–1.50 十档、每 0.10 一档，基准权重依次为 0.5%、1%、2%、4%、8%、22%、30%、23%、7%、2.5%。天空仅轻度向 1.20 收敛，轮廓处将超过 1.30 的字符适度压小。1920×1080 窗口有 35,700 个背景采样位置，其中保留约 32,575 个字符；中心间距约 6.40×9.08 CSS px。海鸥和城市始终为 0.60。 |
| 暗部留白 | 主要疏开左右两侧深色背景和两根窗柱的阴影内侧，随亮度和局部细节平滑过渡；检查原图周围 9 px 的颜色差，无细节的暗部允许整片空出，不限制空洞大小。天空、云、亮部、远景城市与高对比轮廓保留字符，人物暗部只轻度稀疏；窗柱内侧单独按相对明暗稀疏，保留高亮外沿和横跨的缆线。空位固定，不随换字、云或水波反复填满；颜色与字形精度不变。 |
| 全局字形 | 全部保留的背景字符参加换字，包含水面底层、人物、城市、建筑、窗框和太阳。每 12 秒遍历全景，交错替换每个小块的一半字符，约 24 秒覆盖全部保留的字符；三次分散随机后穿插一次带宽范围随机延迟的自上而下推进。只换相近明暗的字形，保持 RGB、坐标和字号；不叠加亮度/颜色扫描带。每帧最多 12 个小块，慢设备延长周期，不积压绘制任务。两套字形在初始化时缓存，动画中图集不增长；每批补绘 16 个小块，再呈现像素及头发遮挡，保留相交笔画。 |
| 物体字形 | 海鸥、纸张、叶片、衣角、眼睛、灯光、鸭子、船和所有漂浮物按约 6 秒周期逐字错开变化。漂浮纹理按物件错开、最多 4 Hz 刷新，位置保持原来的独立合成动画；表情灯光的字符以 2 Hz 采样，眨眼和表情动作仍保留。显示屏的暗色字符底纹以 2 Hz 缓存，波形符号与读数持续更新。 |
| 远景城市 | 与天空、室内和人物共用同一细网格，不在楼体轮廓内裁切或叠加独立网格。边缘采样保留楼顶、窗户及与天空的明暗对比；城市不随云移动；按建筑轮廓固定 0.60 档，退出字号呼吸和水面叠加，保留窗框、前景设备的原有字号。 |
| 三块电脑屏幕 | 保留更细的 ASCII 文本而不二次降采样。四角投影跟随实际显示面的斜向与纵深。中间屏幕覆盖代码、CPU/MEM 侧栏、波形、帧数和底部状态。左屏顶部进一步覆盖约 1–2 层浅色白边，双通道波形与日志按新高度排布。右屏保持完整平行四边形，向右下延伸到头部后方，以贴合发梢的独立轮廓遮挡，保留外边框。波形与屏幕内容随局部绘制更新，目标 60 Hz；CSS 承担四角透视，复用文字纹理，四边羽化。 |
| 左侧白色机器人眼睛 | 只提取两只眼睛的青色 LED。每 3.2 秒短暂眨眼，目光小幅偏移；头壳、天线、身体均固定。眼睛使用更细的字符，保留小尺寸表情。 |
| 机械云灯光 | 只替换中心发光区域。青色、紫色、暖橙、薄荷色平滑过渡，亮度按 4.4 秒周期呼吸，核心保留高光。云形外壳、线路不动。 |
| 红眼机器人 | 在原面板内眨眼、左右转动目光；红色 LED 保持自身颜色，机身不扭动。 |
| 两侧表情机器人 | 左下的双尖括号眼与右侧笑脸，在原面板内切换睁眼、开心眼、眨单眼、惊讶表情；不同相位，每种约 3.8 秒。左下的五官和字符轴共同投影到倾斜面板，保留旁边指示灯与下方信息栏。 |
| 黄鸭与泳圈 | 作为同一个刚性物体，围绕水线中心上下浮动约 4 px，并轻微侧倾约 1.5°。眼睛、鸭嘴和泳圈相对位置不变；水线附近增加扩散涟漪。Life 隐藏入口与合成层中的黄鸭使用同一时钟移动，无标签或悬停提示。 |
| 其他漂浮物 | 中景船、两只罐子、水面纸张、平板、手机、黄色卡片、小纸船与玩具车作为完整物体轻微升降、侧倾；周期分散在 3.7–8.3 秒，初始相位各异，远处船幅度更小。玩具车车顶、轮子与车身一起移动。 |
| 钉在板上的纸 | 九张墙面便笺、板上纸张和显示器旁便条分别提取。固定上缘，偏移随离固定点的距离平方增加；风动频率提高约 1.75 倍，各自使用不同相位。 |
| 云层 | 沿窗外区域单向漂移，速度约 6.8 原图 px/s。减弱与底图的颜色混合强度，保持字符形状和字号稳定，颜色分档由 32 细化为 16，减少跳色与杂点。窗口边缘渐变衔接；窗框、线缆、城市和太阳保持原位。 |
| 吊盆叶片 | 只提取绿色叶片，上部叶尖随风轻动，靠近茎部的位移逐渐趋零。花盆和吊绳固定。 |
| 海鸥 | 沿独立闭合航线飞行，穿插扇翼、滑翔和小幅转弯。五块透明字符画布按屏幕刷新独立移动、转向和扇翼；整景 Worker 的帧间隔不影响飞行。羽翼字符遮挡天空，海鸥不再关联页面入口。所有羽翼字符固定为 0.60 档，合成变换与字符反向缩放配对，飞行透视也不会改变实际字号。 |
| 水面 | 字符位置固定，字形与全局背景一起变化；反光引用对应底层字符的状态，避免叠加不同字符。叠加移动反光、局部椭圆涟漪以及浮鸭附近的波纹。Worker 按 12 Hz 准备相邻时刻的亮度，用三个有上限的缓冲循环复用；浏览器按显示节奏对相邻亮度做加法混合，连续变化且不挪走字符。 |
| 人物与室内结构 | 躯干、手臂、头部、桌椅、屏幕外框保持稳定。衣角末端仅有不足一个像素的起伏；不对人物施加大范围扭曲。 |

原始 PNG 保持不变。浮动和风动物件从原图提取字符，原位置用邻近背景补齐；纸张和叶片保留各自固定点。固定背景先烘焙，再按小块更新全局字形；水面、云层、屏幕、纸张与灯光在 Worker 内更新局部 OffscreenCanvas，由浏览器合成，不传递全景位图。水面只在采样亮度时传递局部位图，消费后立即关闭；三个缓冲提前准备相邻时刻并随显示节奏混合。海鸥和十一组漂浮物的小纹理既换字也独立移动，隐藏入口与浮鸭同步。最多一个绘制请求在途，运动目标 60 Hz，缓慢变化的云纹理和灯光按 30 Hz 更新，暂停及隐藏标签页停止调度。

保留优化前的高 DPI 栅格密度：设备 DPR，上限 2，不因窗口面积增大而降低分辨率。三块显示屏保留 3 倍源纹理；云层、灯光和头发遮挡图层对齐整数 CSS 边界，头发直接复制底图像素，避免合成时二次缩放造成字符模糊和颜色观感变化。字号档位、取色规则、物体坐标与运动速度保持不变；网格间距按当前字号设计独立设置。资源优化依靠局部更新和有上限的缓存：图集按字符/颜色去重，将两套窄字符打包在相近的纹理面积内，初始化后不增长，释放源画布和静态调色缓存；灯光 LRU 上限 2048 格，屏幕文本缓存上限 2 MiB / 384 项。尺寸变化释放旧局部画布。转场采样包括全部动态层和实际屏幕四角。
