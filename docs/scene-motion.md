# 场景动作设计

所有位置都以原图的 1536 × 1024 坐标为准。动作遵循物体的固定点、受力方式和前后遮挡；用户切换减少动态效果或暂停时，整套场景共用的时钟停止。

| 元素 | 实现与边界 |
| --- | --- |
| 字号层次 | 全景约 3.5 px 间距，0.35–0.8 倍十档字号，每 0.05 一档，以中间档位为主。静态场景、屏幕与动态物体共用字号范围，天空保持稳定字形。 |
| 远景城市 | 与天空、室内和人物共用同一细网格，不在楼体轮廓内裁切或叠加独立网格。边缘采样保留楼顶、窗户及与天空的明暗对比；城市不随云移动。 |
| 三块电脑屏幕 | 保留更细的 ASCII 文本而不二次降采样。四角投影跟随实际显示面的斜向与纵深。中间屏幕覆盖代码、CPU/MEM 侧栏、波形、帧数和底部状态。左屏顶部进一步覆盖约 1–2 层浅色白边，双通道波形与日志按新高度排布。右屏保持完整平行四边形，向右下延伸到头部后方，以贴合发梢的独立轮廓遮挡，保留外边框。状态按 30 Hz 更新，复用文字纹理与投影，四边羽化。 |
| 左侧白色机器人眼睛 | 只提取两只眼睛的青色 LED。每 3.2 秒短暂眨眼，目光小幅偏移；头壳、天线、身体均固定。眼睛使用更细的字符，保留小尺寸表情。 |
| 机械云灯光 | 只替换中心发光区域。青色、紫色、暖橙、薄荷色平滑过渡，亮度按 4.4 秒周期呼吸，核心保留高光。云形外壳、线路不动。 |
| 红眼机器人 | 在原面板内眨眼、左右转动目光；红色 LED 保持自身颜色，机身不扭动。 |
| 两侧表情机器人 | 左下的双尖括号眼与右侧笑脸，在原面板内切换睁眼、开心眼、眨单眼、惊讶表情；不同相位，每种约 3.8 秒。左下的五官和字符轴共同投影到倾斜面板，保留旁边指示灯与下方信息栏。 |
| 黄鸭与泳圈 | 作为同一个刚性物体，围绕水线中心上下浮动约 4 px，并轻微侧倾约 1.5°。眼睛、鸭嘴和泳圈相对位置不变；水线附近增加扩散涟漪。Life 隐藏入口随黄鸭在当前场景帧中的轮廓移动，无标签或悬停提示。 |
| 其他漂浮物 | 中景船、两只罐子、水面纸张、平板、手机、黄色卡片、小纸船与玩具车作为完整物体轻微升降、侧倾；周期分散在 3.7–8.3 秒，初始相位各异，远处船幅度更小。玩具车车顶、轮子与车身一起移动。 |
| 钉在板上的纸 | 九张墙面便笺、板上纸张和显示器旁便条分别提取。固定上缘，偏移随离固定点的距离平方增加；风动频率提高约 1.75 倍，各自使用不同相位。 |
| 云层 | 沿窗外区域单向漂移，速度约 6.8 原图 px/s。减弱与底图的颜色混合强度，保持字符形状和字号稳定，颜色分档由 32 细化为 16，减少跳色与杂点。窗口边缘渐变衔接；窗框、线缆、城市和太阳保持原位。 |
| 吊盆叶片 | 只提取绿色叶片，上部叶尖随风轻动，靠近茎部的位移逐渐趋零。花盆和吊绳固定。 |
| 海鸥 | 沿独立闭合航线飞行，穿插扇翼、滑翔和小幅转弯。五块透明字符画布按屏幕刷新独立移动、转向和扇翼；整景 Worker 的帧间隔不影响飞行。羽翼字符遮挡天空，海鸥不再关联页面入口。 |
| 水面 | 固定字符底层，叠加移动反光、局部椭圆涟漪以及浮鸭附近的波纹，避免挪走字符形成黑缝。 |
| 人物与室内结构 | 躯干、手臂、头部、桌椅、屏幕外框保持稳定。衣角末端仅有不足一个像素的起伏；不对人物施加大范围扭曲。 |

原始 PNG 保持不变。浮动和风动物件从原图提取字符，原位置用邻近背景补齐；纸张和叶片保留各自的固定点。动画在独立 Worker 内绘制并传回完整画面，页面主线程保留给鼠标、键盘和触摸响应；同一时间只提交一帧。云层复用固定字符遮罩进行连续色彩合成，漂浮物复用刚性纹理，屏幕与表情复用缓存。取消整景 30 fps 限制，实际刷新速度取决于设备，全部动作共用真实时间；暂停、页面隐藏及调整尺寸会丢弃过期帧。字符颜色查表和图集预热避免重复计算与纹理上传。

回归检查覆盖场景入口、小黄鸭的移动点击区域、整景阻塞期间持续的飞行与扇翼、固定的躯干与手臂、水面覆盖率、独立屏幕更新、眼睛眨动、浮鸭刚性、纸张固定端、云与窗框的分离、混合字号、移动端、暂停与减少动态效果。
