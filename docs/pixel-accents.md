# 原先静止区域的 18 处新增动态

沿用 1536×1024 原生 1× 像素。`scene-accents.js` 保存新增位置和动作；三张纸复用现有物体合成，盆栽单独保留固定根部。原图与已有的云、水面、风扇、三块主屏不重绘。

| 位置 | 动作 |
| --- | --- |
| 左上墙面的蓝色大纸张 | 上缘固定，纸页下缘轻摆 |
| 最左侧中部白色纸张 | 固定上缘，随另一阵风轻摆 |
| 最左侧黄色便笺 | 小幅翘动 |
| 左下水面的灰色手柄 | 方向键和按钮分时轻按，外壳与水线固定 |
| 左上小诊断面板 | 点阵数据滚动与游标移动 |
| 红眼机器人左下的小蓝屏 | 三行终端信息交替更新 |
| 桌面左侧灰色小设备 | 原面板内眨眼、目光与嘴形变化 |
| 右侧上方小笔记本 | 日志输入及光标闪动 |
| 右侧倾斜小键盘面板 | 三段信号依次响应 |
| 左墙电源模块 | 原红绿指示灯错开亮暗 |
| 左侧浅色主机 | 原红色读写灯短促活动 |
| 桌下机柜底部 | 青色网络状态灯分段活动 |
| 右侧小音箱下方 | 原绿色电平格交错变化 |
| 右侧音箱 | 振膜内部的明暗和像素圈轻振，外圈固定 |
| 右侧青色机箱表面 | 局部反光缓慢经过，限定在原青色材料上 |
| 桌面设备亮面 | 短小反光缓慢经过，避开暗部与物体边界 |
| 桌面左侧蓝杯 | 三缕错开的像素蒸汽，杯身固定 |
| 窗下中间小盆栽 | 根部固定，绿叶向上逐渐增加摆幅 |

全部动作共用场景时钟，暂停、后台、减少动态效果和页面切换沿用原有行为。新小屏幕以 12 Hz 更新小纹理，位置固定；微小的像素蒸汽与植物姿态按主循环更新。初始化后不读取画布像素，不创建新画布，不使用额外定时器。

纸张和植物采用原图裁片，昼夜切换由现有光照系统处理。新增面板在切换时更新颜色；原 LED 使用固定遮罩改变亮度，保留自身轮廓。反光经原材料遮罩裁切，不越过机壳边缘。

`tests/scene-accents.cjs` 检查 18 处实际像素变化、固定外壳和根部、物体静止时原色完整、连续帧无扫描分裂、反光无越界、确定性、四种光照可逆，以及画布缓存上限。本地 Chromium 检查新增纹理共 136,468 字节，单次绘制 p95 约 1 ms；主页面采样约 50 fps，实际表现随设备与负载变化。
